\begin{abstract}
现有具身智能基准主要评估有限时长内完成外部给定任务的能力，难以刻画人类持续活动、环境演化与机器人干预相互作用下的长期维护问题。我们提出 GraphWorld，一个面向人机世界共生（human-agent world symbiosis）的动态图评测基准，将家庭、医院、超市、办公室和工厂统一表示为持续演化的层次化场景图，使房间、物体、设备、NPC 与机器人共享同一状态转移、局部观测和动作验证机制。GraphWorld 通过 NPC 日程事件和设备过程持续产生状态偏离，并以状态健康、空间秩序和人类事件支持三类累计指标衡量机器人能否发现、排序、执行并恢复维护任务。基于五个场景、三种图结构 profile、三类日程扰动和 800 步长期运行实验，我们比较了 reactive、single-round 与 goal-review 策略，并在 Qwen3.5-9B、DeepSeek-R1-14B 和 Llama-3.1-8B 上进行评估。无机器人基线的平均综合分为 0.5184；DeepSeek-R1-14B 的 goal-review 达到 0.7240，相对提升 0.2056。在额外的阻塞恢复诊断中，goal-review 的人类流程恢复率为 0.700，而 reactive 仅为 0.002。结果表明，结构化任务组织能够显著改善长期世界维护，但现有 LLM agent 仍受局部目标吸引，在全局优先级排序、阶段保持和中断恢复方面存在明显不足。GraphWorld 为研究具身智能从孤立任务执行走向长期人机--环境共生提供了统一的运行时与评测基础。
\end{abstract}

\section{引言}
现有 Embodied AI 的主流评测大多围绕有限时长、明确目标的单次任务展开。无论是导航、抓取、语言条件操作，还是更复杂的长程任务分解，系统通常从一个初始状态出发，在有限 episode 中完成一个给定目标。然而真实部署环境并不会在一次任务结束后停止变化：人类会持续移动物体、消耗资源、制造脏乱并引入新的流程阻塞，环境状态又反过来决定后续人类活动是否能够顺利进行。家庭、医院、超市、办公室和工厂虽然表面任务不同，但都共享同一个更一般的闭环：人类活动持续改变环境，机器人持续调节环境，环境继续支持后续人类活动。本文将这一问题定义为人机世界共生（human-agent world symbiosis）：给定一个被人类活动持续扰动的动态场景图，具身智能体如何通过长期环境调节，使世界保持可用、有序，并持续支持人类的日常或职业活动。这个问题的关键不再只是“完成一个任务”，而是能否在不断出现的多类环境偏离之间进行长期任务调度、阶段保持与中断恢复。

围绕这一目标，现有研究已经从多个方向逼近相关能力。传统具身任务基准擅长评估给定目标下的感知、grounding 和短程执行，但任务边界通常由外部显式给出，环境变化也主要服务于单个 episode。长程规划与语言模型智能体方法进一步关注任务分解、记忆与反思，能够在较长链条上组织动作，但大多仍假设任务目标已经明确，而不是从持续扰动的世界中自主抽取维护任务。另一方面，持续世界与人类行为模拟工作展示了长期运行的人类角色、日程和社会活动，却往往缺少对机器人动作合法性、可恢复状态以及系统性评测的统一支持。因此，现有路线之间仍缺少一个统一 benchmark：它既能表示持续演化的人类扰动世界，又能让场景表示、人类事件、动作执行与评分共享同一动态状态空间。

我们对这一问题的核心判断是：持续动态世界中的主要瓶颈并不在于机器人是否“知道某个技能”，而在于它能否从不断积累的环境偏离中抽取任务、判断优先级、保持阶段执行，并在中断后恢复高价值流程。基于这一认识，我们构建了 GraphWorld。它把房间、物体、设备、NPC 和机器人统一建模为一个持续演化的层次化场景图，并将 NPC 事件、设备周期、动作 schema、局部感知和长期评分机制统一到同一个 graph-native runtime 中。在这个设定里，任务不再来自外部给定指令，而是来自人类活动留下的状态偏离、空间偏离和流程阻塞；机器人行为也不再只由最终成功与否评价，而是由其对长期共生闭环的调节能力来评价。围绕这一框架，我们设计了多场景、多 graph profile、多日程扰动的实验，并引入状态、空间和人类事件三类长期评分，以及用于诊断任务调度失败机制的分析视角。

实验结果表明，结构化机器人策略通常优于无机器人基线和纯 reactive 策略，说明 GraphWorld 中的大部分问题具有明确的可恢复性；但在 Qwen3.5-9B、DeepSeek-R1-14B 和 Llama-3.1-8B 实验中，LLM agent 仍表现出局部目标固着、阶段任务闭环不足，以及对关键人类阻塞问题恢复不稳定等现象。更强模型和结构化的 goal-review 策略能够带来改进，但长期任务调度仍是主要瓶颈。换言之，GraphWorld 所揭示的困难并不主要来自单步动作生成，而是来自持续动态世界中的长期维护决策本身。

本文贡献如下：
\begin{itemize}
  \item 我们提出并形式化了人机世界共生这一新评测问题，将具身智能从完成孤立任务推进到持续人类扰动下的人机--环境闭环调节。
  \item 我们提出 GraphWorld，一个 graph-native runtime，使场景表示、人类事件、动作合法性验证和长期评分共享同一个持续演化的符号状态，并支持多场景、多 profile 与多日程扰动实验。
  \item 我们通过系统实验和诊断分析表明，现有 LLM agent 的主要局限不在孤立动作生成，而在长期任务优先级排序、阶段保持与恢复能力，这为后续显式调度机制研究提供了评测基础。
\end{itemize}

\section{相关工作}
\subsection{具身与开放式评测}
具身智能评测的核心差异首先体现在“评测单位”上。若 benchmark 以单个 episode 和外部给定目标为单位，智能体主要被考察的是指令理解、局部 grounding、动作可行性和终止条件达成；但真实服务环境并不在一次任务结束后重置。人类会反复使用同一空间，制造脏污、移动关键物体、消耗资源、打开设备并留下流程前置条件。于是困难从“如何完成这一条指令”转变为“如何在持续积累的世界偏离中发现任务、排序任务并维持后续活动可用性”。这一转变正是 GraphWorld 关注的 benchmark 问题。

更广义的 AGI evaluation 综述已经指出，静态、任务特化和封闭测试集分数难以充分说明系统是否具有广泛能力、稳健部署能力、长程执行能力和对齐约束下的决策能力~\cite{agisurvey2024,agieval2025}。在具身语境下，TongTest 进一步将评测环境明确为动态、具身、物理和社会交互系统，并强调无限任务、自驱任务生成、价值对齐和因果理解~\cite{tongtest2024}；C-U-V framework 则把 agent 的认知结构、能力函数和价值函数放在统一形式化空间中讨论，说明智能应在与物理环境和其他智能体的交互中被评价~\cite{cuv2026}。这些工作为 GraphWorld 提供的是评测哲学和问题动机：智能体不应只在固定题库里回答问题或完成给定目标，而应在开放动态世界中长期维持有价值的行为后果。

具体到具身 benchmark，ALFRED、VirtualHome、BEHAVIOR-1K 和 Habitat 3.0 等工作已经推动了家庭场景、程序化日常活动、丰富对象状态和人机共居环境的发展~\cite{alfred2020,virtualhome2018,behavior1k2024,habitat3_2023}。近期 Daily Composite Tasks 也开始在动态家庭环境中考察多模态大模型的对象理解、空间智能和社会活动能力~\cite{dailycomposite2025}。这些工作说明，具身评测已经从单步操作走向复杂活动链条和人类场景。然而，它们多数仍以预定义任务、episode success 或 composite task performance 为主要评价对象；人类活动即使出现，也通常作为任务背景或任务内容，而不是持续生成维护压力的世界动力学。GraphWorld 的区别在于，任务不是外部列好的 item，而是人类长期使用世界后自然产生的状态偏离、空间偏离和流程阻塞；评价对象也不是某个活动是否完成，而是智能体能否长期维护世界的可用性、秩序和人类活动支持能力。

\subsection{场景图与长程机器人规划}
一旦评测目标从单次任务完成转向长期世界维护，世界表示就不能只是静态地图或视觉上下文。它必须保存对象身份、空间层级、动态关系、可变状态、设备周期、人类事件前置条件和动作后果；同时，观察、动作合法性、状态转移和评分也需要在同一表示上闭环。场景图和语义地图正是解决这一问题的重要基础。Hydra、ConceptGraphs 和 Taskography 等工作展示了 3D scene graph 在空间层次、对象关系、开放词汇感知和任务规划评估中的价值~\cite{hydrarss2022,conceptgraphs2024,taskography2022}。

长程机器人规划进一步说明，结构化世界表示需要与动作选择和反馈机制结合。SayCan 将语言模型规划与 affordance grounding 结合，Inner Monologue 引入环境反馈和中间推理，SayPlan 利用 3D scene graph 支持大规模机器人任务规划~\cite{saycan2022,innermonologue2022,sayplan2023}。已有 HLR 等状态感知闭环规划工作也表明，层次化场景图能够帮助机器人在复杂环境中组织多步任务~\cite{hlr2025}。这些工作共同说明，图、可供性、语言模型和执行反馈能够支撑更长链条的机器人行为。

但在多数已有工作中，图仍主要作为感知输出、语义地图或任务 grounding 的中间表示：目标由外部给定，图服务于规划如何到达目标。GraphWorld 中的图承担更基础的角色。它不是规划器的辅助输入，而是运行时世界本体：节点状态、空间关系、人类事件、设备周期、动作效果和事件日志都在同一动态图中随时间更新；机器人观察来自该图，动作 schema 在该图上验证，NPC 事件在该图上检查前置条件并写入效果，长期评分也直接从图状态中计算。因此，GraphWorld 将 scene graph 从“任务规划表示”推进为“评测世界状态转移系统”，使扰动、动作、观察和评价共享同一个 graph-native substrate。

\subsection{人类中心与价值感知智能体评测}
如果长期服务机器人只被评价为是否清洁了物体、移动了物体或完成了某个技能，仍然会遗漏一个核心问题：这些行为是否让人类活动继续可行。人类中心和价值相关评测已经指出，智能体能力不能只由工具性成功率衡量。Social intelligence benchmark 关注模型是否能够理解他人意图、社会动态和递归推理~\cite{socialintelligence2024}。RVBench 从角色价值角度评估 role-playing LLM 的价值取向一致性~\cite{rvbench2025}。Value soft alignment 研究机器人如何识别人类短期行为与长期价值之间的不一致，并在适当时提供建议~\cite{valuesoftalignment2024}。LLM psychometrics 则从心理测量学角度讨论人格、价值、智能和社会能力的评估方式~\cite{llmpsychometrics2026}。

这些工作共同说明，面向人类环境的智能体不应只优化局部动作结果，还应考虑行为是否支持人类目标、社会规范和长期价值。但许多社会/价值评测主要发生在语言问答、问卷、角色扮演或局部交互中，较少把价值后果落到可执行、可验证、会随时间累积的物理世界状态中。GraphWorld 不直接评估抽象人格或价值观，而是采用更操作化的定义：如果一个世界仍然支持人类日程中的关键活动，那么机器人对这个世界的维护就是有价值的。药品是否回到药房、冷柜是否关闭、购物车是否在入口、治疗床是否清洁、文件是否归档，这些不是孤立物体属性，而是后续人类事件能否发生的前置条件。

因此，GraphWorld 将 human-centered evaluation 转化为两类可测后果：一是 human event score，即截至当前时刻人类日程事件是否因世界状态被维护而成功；二是 blocking recovery，即当人类活动因可恢复前置条件失败而阻塞后，机器人是否在后续步骤中修复该条件。这样的设计避免把“价值”停留在抽象问卷或语言判断上，而是把它落实为动态世界是否继续支持人类活动。综上，已有工作分别提供了开放式具身评测理念、日常活动 benchmark、图结构规划表示以及社会/价值评测信号，但这些要素通常被分开研究。GraphWorld 填补的缺口在于，将它们统一到一个长期动态图世界基准中：人类活动持续扰动环境，机器人动作修改同一运行时图，智能体通过状态健康、空间恢复和人类活动支持三类累计指标接受评测。GraphWorld 因而不是又一个单次任务完成基准，而是面向人机世界共生的长期世界维护评测基准。

\section{方法}
\subsection{问题定义：人机世界共生}
我们将世界表示为随时间演化的动态图：
\begin{equation}
\mathcal{G}_t = (\mathcal{V}, \mathcal{E}^s, \mathcal{E}^d_t, \mathcal{X}_t, \mathcal{H}_t),
\end{equation}
其中 $\mathcal{V}$ 是房间、物体、设备、人类和机器人节点集合，$\mathcal{E}^s$ 是稳定结构边，$\mathcal{E}^d_t$ 是运行时动态关系，$\mathcal{X}_t$ 是节点状态，$\mathcal{H}_t$ 是世界时间、事件日志和可见性上下文。人类活动过程 $P_h$ 持续扰动图，机器人策略 $\pi$ 基于局部观察 $o_t$ 和内部目标记忆 $m_t$ 选择动作：
\begin{equation}
a_t \sim \pi(o_t, m_t).
\end{equation}
人机世界共生的目标是在长时程内最大化环境对持续人类活动的支持能力：
\begin{equation}
\max_{\pi} \frac{1}{T}\sum_{t=1}^{T} U(\mathcal{G}_t),
\end{equation}
其中 $U$ 同时度量状态健康、空间秩序和人类活动支持程度。

\subsection{动态图世界}
GraphWorld 的节点包括 room、fixed object、movable object、control object、human 和 robot。结构关系描述房间连通、容器包含、设备控制和固定支撑；动态关系描述物体当前位姿，例如 \texttt{in}、\texttt{on}、\texttt{near}、\texttt{held\_by} 和 \texttt{worn\_by}。状态空间只保留预定义离散或数值状态，例如 \texttt{is\_dirty}、\texttt{is\_open}、\texttt{is\_on}、\texttt{is\_wet}、\texttt{folded}、\texttt{is\_rotten}、\texttt{temperature}、\texttt{fill\_level} 和 \texttt{remaining\_cycle}。

场景构建采用静态图变体。每个 base scene 可以生成不同 topology 和 object-interaction profile：\texttt{compact\_cleaning} 让关键物体更集中并突出清洁需求；\texttt{normal\_logistics} 保持正常拓扑并突出搬运、归位和补给；\texttt{spread\_device} 拉远关键房间和设备，强调设备链和跨房间依赖。这样，同一场景类型可以产生不同难度，而不必依赖新的场景类别堆叠。

\subsection{人类事件模型}
NPC 是 GraphWorld 的核心扰动源。每个 NPC 由角色、日程和事件序列定义。事件包含前置条件和效果：前置条件判断人类活动能否成功，效果将活动结果写回图状态。例如病人取药要求处方和药盒存在；护士送药会移动冷藏药；工厂工人准备上岗会取走安全装备；顾客购物会移动商品、使用购物车并影响冷柜或收银区状态。

我们用五类活动驱动描述 NPC 行为来源：\texttt{bodily\_need}、\texttt{health\_safety}、\texttt{role\_duty}、\texttt{social\_coordination} 和 \texttt{creative\_improvement}。这些类别用于解释不同场景中人类为什么持续使用和扰动环境。家庭主要由 bodily need 驱动，医院和工厂强调 health safety 与 role duty，办公室和超市则更多体现 social coordination 与流程服务。

\subsection{动作 Schema 与合法性}
机器人动作采用 PDDL 风格的 action schema：
\begin{equation}
\text{schema} = (\text{parameters}, \text{preconditions}, \text{effects}).
\end{equation}
动作空间包括 \texttt{move}、\texttt{pick}、\texttt{place}、\texttt{open}、\texttt{close}、\texttt{press}、\texttt{brush}、\texttt{fold} 和 \texttt{dump}。合法性检查与效果执行分离：predicate 只判断同房间、手持物、容器可访问、容量、设备门、动作 affordance 等条件；effect 只执行移动节点、开关、清洁、折叠、倒空和设备启动等状态更新。这种边界避免把动作语义、物体规则和运行时副作用混在同一段逻辑中。

动作规则显式阻止不合理捷径。例如布类物体不能通过普通 \texttt{brush} 直接清洁，必须经过洗衣机、晾衣架、折叠和收纳；垃圾桶只接收腐烂或烧焦食物，并需要在垃圾站 \texttt{dump} 后恢复；杯子有液体时需要在水槽倒空；设备门未关闭时不能启动周期。这些约束保证 agent 不能靠非法或过度简化动作刷分。

\subsection{Agent 方法}
我们比较四类方法。No-robot 只运行 NPC 和环境转移。Reactive agent 只根据局部观察、最近分数和合法动作空间进行一步反应。Single-round agent 在一次 LLM 调用中同时选择高层任务和低层动作。Goal-review agent 先判断是否继续、切换、完成或放弃当前 active goal，再选择低层动作。

GraphWorld 中的技能库作为 procedural prior 使用。洗衣、倒垃圾、补药、归还冷藏药、整理购物车、归档文件和归还 PPE 等流程具有相对固定的正确阶段；真正的研究问题是机器人是否知道什么时候启动该流程、是否坚持执行、是否在新扰动出现时切换，以及任务中断后能否恢复。因此，技能库定义“决定做某类待恢复状态后怎么做”，而实验评估“在持续扰动世界中该先做什么、做到何时、何时切换”。

\subsection{评分}
GraphWorld 使用三类分数。记 $\mathbb{I}[a \ne b]$ 为指示函数：当两个变量不一致时取 1，否则取 0。状态分数衡量对象状态是否健康：
\begin{equation}
S_{\mathrm{state}}(t) = 1 - \frac{\sum_{i,j} M_{ij}\, \mathbb{I}[X_{ij,t} \ne X^{*}_{ij,t}]}{\sum_{i,j} M_{ij}},
\end{equation}
其中 $M$ 是状态 mask，只统计该对象实际拥有的状态维度。空间分数衡量可移动物体是否处于合理关系：
\begin{equation}
S_{\mathrm{spatial}}(t) = 1 - \frac{1}{|\mathcal{O}|}\sum_{o\in \mathcal{O}} \mathbb{I}[r_t(o) \ne r^{*}_t(o)].
\end{equation}
人类事件分数衡量 NPC 日程事件是否成功：
\begin{equation}
S_{\mathrm{human}}(t) = \frac{N_{\mathrm{success}}(1:t)}{N_{\mathrm{attempt}}(1:t)}.
\end{equation}
综合分数为
\begin{equation}
S(t)=0.45S_{\mathrm{state}}(t)+0.35S_{\mathrm{spatial}}(t)+0.20S_{\mathrm{human}}(t).
\end{equation}
实验同时记录 instant score 和平均曲线。Instant score 展示当前世界状态，平均曲线展示长期共生闭环的稳定性。

除上述连续分数外，我们还记录人类阻塞恢复率作为补充诊断指标。当某个人类事件由于可恢复前置条件失败而无法完成时，记为一个 blocking case；如果后续世界状态重新满足该前置条件，并且恢复轨迹中存在机器人动作介入，则记为一次恢复。设 $B$ 为可恢复 blocking case 总数，$R$ 为恢复数，则
\begin{equation}
S_{\mathrm{block}} = \frac{R}{B}.
\end{equation}
该指标不参与主综合分数，而用于分析 agent 是否真正恢复了会阻塞后续人类活动的关键条件。

\section{实验}
\subsection{实验设置}
我们在五个 base scenes 上实验：家庭、医院、超市、办公室和工厂。家庭包含 1 个 resident；其余场景包含 3 个 NPC，分别覆盖病人/护士/医生、顾客/收银员/理货员、员工/经理/访客、工人/质检员/维修员。所有主实验运行 800 step，机器人设置为 1 个机器人，LLM 主实验使用 Qwen3.5-9B；规则基线不调用 LLM。

实验分四组。主实验评估 5 个 base scene、固定日程和 4 种方法。规则调度基线在相同 800 step fixed schedule 下加入 nearest-repair 和 human-blocking-first 两种无 LLM 策略，用于检验 GraphWorld 是否确实测量长期维护调度，而不只是 prompt 技巧。多样性实验评估 5 个场景、3 种 graph profile 下的 goal-review 方法，并加入对应 profile 的 no-robot raw baseline。日程随机性实验评估 5 个 base scene、fixed/calendar/stochastic 三类日程下的 goal-review 方法。四组实验分别回答方法是否有效、基准是否具有构念有效性、场景难度变化是否可区分、以及人类扰动模式变化是否影响结果。

\subsection{主实验：Agent 是否能稳定共生闭环}
图~\ref{fig:main-grid} 展示 base graph 上的主实验曲线。总体上，带任务结构的 agent 比 reactive 更稳定，尤其在 office 和 factory 等空间秩序强依赖场景中提升显著。表~\ref{tab:main-results} 给出 step 799 的累计平均分数。Single-round 在 hospital、supermarket、office 和 factory 中取得最高 final score；goal-review 在 home 中表现最好。这说明没有单一方法在所有场景中占优：goal-review 在家庭这类人类事件密集、需要长期坚持流程的场景中更有优势，而 single-round 在空间归位回报明确、可快速执行搬运和放置链条的场景中更果断。

更细地看，三类分数揭示了 agent 改善世界的不同机制。Office 和 factory 中 single-round 的优势集中体现在 spatial score：它把 spatial 拉高到 0.975 和 0.985，能快速归还文件、工具、PPE 和零件箱，使人类职业流程恢复可用，但 factory 的 state score 仍只有 0.423，说明设备链和状态恢复并未同步完成。Hospital 中 single-round 的提升同样以 spatial 为主（0.685），并把 human event score 拉满到 1.000，说明医院场景的关键不是单个状态清洁，而是处方、药品、病床和医疗垃圾等对象是否回到流程可用位置。Supermarket 中 single-round 的 spatial 和 human score 同时较高（0.905 和 0.833），说明一次性输出高层任务与低层动作已经足以稳定推进补货和顾客事件链。Reactive 虽然有时能维持较高 state score（office 0.652、hospital 0.619），但缺少跨房间归位和流程恢复能力，spatial 明显低于结构化方法。

这一结果也解释了为什么 GraphWorld 需要拆分指标。不同 agent 的表面分数可能接近，但其行为机制不同：有的主要清洁局部状态，有的主要恢复空间秩序，有的能支撑人类事件继续发生。三维评分使这些差异可以被拆开观察，避免被单一 success rate 掩盖。

结果显示，模型主干能力会改变长期共生表现，但这种影响与 agent 策略耦合。三个模型的 single-round 平均分接近（Qwen 0.6838、DeepSeek 0.6808、Llama 0.6749），说明一次性高层任务选择在不同主干上都能稳定触发搬运和归位链条。DeepSeek 在 goal-review 上最高（0.7240），Llama 次之（0.6826），Qwen 为 0.6548，说明“是否继续当前目标”和“下一步动作选择”拆开后，更强的推理主干更能利用复审阶段保持长链任务上下文。Reactive 的差异较小，且 Llama reactive 平均分略低于 no-robot baseline（0.5128 对 0.5184），表明仅替换模型并不能弥补缺少高层任务结构的问题。

因此，模型对比支持两个结论。第一，GraphWorld 对 backbone 能力敏感，尤其在需要目标复审和阶段保持的策略中更明显。第二，策略结构仍然重要：DeepSeek 的 goal-review 比 reactive 高 0.1733，Qwen 的 single-round 比 reactive 高 0.1495，Llama 的 goal-review 比 reactive 高 0.1697，说明长期共生能力来自模型理解能力和任务组织机制的共同作用。

\subsection{多样性实验：Graph Profile 是否拉开难度}
图~\ref{fig:diversity-grid} 展示三种 graph profile 下 goal-review 与 no-robot baseline 的结果。该实验不改变模型、方法和日程，只改变同一 base scene 中关键物体、房间拓扑和设备链压力，用于检验图结构本身是否会改变长期调度难度。800 step 结果显示，profile 对不同场景的影响并不一致：hospital、office 和 factory 在 compact profile 下更容易取得高分，而 home 和 supermarket 在 spread profile 下反而更高。这说明 profile 不是简单的“越分散越难”，而是在改变可见目标、跨房间搬运、设备链和人类事件窗口之间的平衡。

  \centering
  \includegraphics[width=\textwidth]{figures/overview/diversity_profile_grid.png}
  \caption{Graph 多样性实验。实线为 Qwen3.5-9B goal-review，虚线为对应 no-robot raw baseline；颜色表示 compact、normal 和 spread 三种 profile。各子图为累计平均 final/state/spatial/human 分数。}
  \label{fig:diversity-grid}
\end{figure*}

具体来看，hospital compact 的 final score 为 0.7815，明显高于 normal 的 0.6121 和 spread 的 0.6973，说明医疗场景中把关键药品、床位和医疗废物链条压缩到更短拓扑后，goal-review 更容易维持完整流程。Factory 也呈现类似趋势：compact 为 0.6806，normal 为 0.5810，spread 下降到 0.4430，说明生产场景中的 PPE、零件箱、设备和质检记录一旦被拉散，agent 容易被局部清洁或近处物体吸引，难以稳定完成生产链恢复。Office 中 compact 和 normal 接近，spread 略低；home 与 supermarket 则在 spread 下更高，说明部分生活和零售任务受益于更清晰的空间分区或更少的局部竞争目标。

因此，graph profile 的作用在于改变 agent 面临的调度结构，而非简单增加物体数量。\texttt{compact\_cleaning} 主要考察局部清洁和短链恢复，\texttt{normal\_logistics} 考察跨房间搬运和补给，\texttt{spread\_device} 引入更远拓扑和设备依赖。Factory spread 的失败说明，当任务需要从局部清洁转向生产链恢复时，LLM agent 很容易停留在“看见什么修什么”的策略层级，而没有形成面向流程的全局优先级。

\subsection{日程随机性实验：扰动模式是否影响方法表现}
图~\ref{fig:schedule-goal-review} 展示 800 step 下 goal-review 在 fixed、calendar 和 stochastic 三类日程中的表现。该实验控制模型、场景和 agent 方法不变，只改变 NPC 事件发生顺序和日程扰动方式，用于检验同一策略是否对人类活动节奏敏感。结果显示，日程扰动会改变环境偏离累积轨迹，但不是所有场景都同样敏感。Home 和 supermarket 中三类日程差异较小，说明 goal-review 对生活和零售流程中的常见扰动具有一定稳健性；hospital 的 calendar 设置低于 fixed/stochastic，说明医疗流程对事件时序更敏感；office 和 factory 的 stochastic 分数反而更高，说明随机化有时会打散固定日程中连续积累的局部阻塞，使 agent 获得更多恢复窗口。

  \centering
  \includegraphics[width=\textwidth]{figures/overview/goal_review_schedule_avg_grid.png}
  \caption{800 step 日程随机性实验。曲线为 Qwen3.5-9B goal-review 在 fixed、calendar 和 stochastic 三类日程下的累计平均 final/state/spatial/human 分数。}
  \label{fig:schedule-goal-review}
\end{figure*}

这一结果说明，GraphWorld 不只是证明某个 agent 更强，也能揭示同一 agent 在不同人类扰动节奏下的稳定性。Fixed schedule 给出可重复的基准轨迹；calendar schedule 引入工作日/时段结构，使人类事件更接近真实流程；stochastic schedule 在日程框架内打乱部分事件顺序，用于测试 agent 是否依赖固定事件先后关系。Goal-review 在大多数场景中保持高于或接近 fixed 的表现，但 hospital 的下降表明，仅靠目标复审仍不足以处理强流程依赖场景中的时序窗口。

从日程角度看，场景敏感性与人类流程的耦合程度有关。Home、hospital 和 factory 对事件顺序更敏感，因为穿衣、取药、上岗、生产和质检都依赖前序对象是否可用；一旦机器人错过恢复窗口，后续事件会连续失败。Supermarket 和 office 的部分活动更像可并行服务流，单个事件失败不一定立即阻断全天流程，因此曲线更平滑。这个现象说明，GraphWorld 的随机日程用于区分“局部修补型 agent”和“能理解流程依赖的 agent”。

我们观察到三种稳定模式。第一，\emph{空间恢复优先}：agent 更容易理解“物体应放回哪里”，因此 spatial score 往往比 state score 更容易被拉开。第二，\emph{状态流程断裂}：洗衣、冷链、设备运行、床单更换和生产质检都需要多步动作与时间过程，agent 一旦中途切换，state score 就长期无法恢复。第三，\emph{局部目标吸引}：模型倾向选择最近、最显眼、动作结果最确定的目标，例如桌面、柜门、按钮和当前房间对象。这些模式解释了为什么结构化机器人策略能改善世界状态，但仍没有达到稳定共生。

\subsection{失败分析：为什么现有 Agent 仍然不够}
最明显的失败来自局部可见偏离吸引。LLM 在每一步看到合法候选和可见状态时，很容易选择最近、最确定、语义最直接的动作，例如清洁当前房间的桌子、关闭当前可见柜子或移动到最近控制物。只要 NPC 事件持续制造这些局部可见偏离，agent 就会反复处理低价值任务，而忽略跨房间、跨设备、跨人类事件的长链任务。

第二个失败来自状态偏离和空间偏离的不同步。机器人很擅长把物体归位，因此 spatial score 往往被拉高；但 state score 需要完成设备链、等待周期和后续收纳，例如洗衣、冷链、机器运行和床单更换。若 agent 不能保持任务阶段，它可能完成一半流程后切走，导致状态偏离长期存在。

第三个失败来自缺少显式全局任务队列。现有 active goal 是局部记忆，而不是一个可排序、可抢占、可恢复的任务池。更合理的下一步是把每个待恢复任务实例化为 task object，记录其价值、紧急度、距离、依赖、预计耗时和对 human event 的影响，再由调度器选择技能流程。

这些失败并不是简单的模型不够大。即使给定技能库和合法动作空间，agent 仍然需要判断任务价值、流程阶段和切换时机。换言之，GraphWorld 将问题从“能否生成合法动作”推进到了“能否在动态世界中组织长期行为”。这也是我们认为该 benchmark 有研究价值的地方：它把 LLM agent 的短程常识能力和长期调度能力分离开来，使后者成为可以被系统测量的问题。

\section{讨论}
GraphWorld 的核心是把已知技能放到持续扰动世界里，评估 agent 是否能长期调度它们。因此，技能库将评测焦点从“模型是否知道洗衣常识”转移到“模型能否在多类环境偏离之间进行长期共生调节”。本文加入的规则调度基线已经表明，局部修补和阻塞优先都只能覆盖长期维护问题的一部分；未来仍可进一步加入 oracle skill upper bound，估计完美调度且完美执行所有技能时的分数上界，从而更精细地区分场景/评分限制和 agent 调度限制。

多场景设计服务于同一个抽象问题。Home、hospital、supermarket、office 和 factory 分别代表生活秩序、健康安全流程、零售补给、协作信息流和生产流程。未来加入 warehouse 或 greenhouse 时，也应按同一抽象扩展：仓储调节库存、通道和拣货流；农业大棚调节作物状态、温湿度、灌溉和工具流程。这样 GraphWorld 可以作为 human-agent world symbiosis 的统一基准，而不局限于某个单一 domain 的任务集。

限制主要有三点。第一，NPC 事件仍带有模板化设计，一些事件会持续制造局部状态偏离，可能过强地吸引 agent。第二，评分中的合理状态仍主要基于稳态目标，未来需要更多 activity-conditioned target，例如吃饭时餐具在桌上是合理的，饭后才成为待恢复状态。第三，多机器人虽然在数据结构上可表示，但缺少强仲裁和资源 claim 机制，尚不能系统研究多机器人协同调节。

\section{结论}
本文提出 GraphWorld，一个面向人机世界共生的动态图评测基准。GraphWorld 将具身智能评测从完成孤立指令推进到在持续人类扰动下调节多样化动态世界。通过层次化场景图、NPC 事件、动作 schema、局部感知、技能条件化 agent 和三维长期评分，GraphWorld 能够系统分析机器人如何调节状态健康、空间秩序和人类活动支持能力。五个场景、三类 graph profile 和多种日程扰动的实验表明，结构化 LLM agent 能改善世界状态和空间秩序，但仍缺少稳定的全局任务调度能力。我们认为，人机世界共生将成为服务机器人从单次任务执行走向长期共处的重要评测方向。
